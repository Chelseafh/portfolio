Beca de I+D ALTEN Spain & Inst. Cervantes

Controlador XR & Portal de Gestión VR/MR

Ecosistema distribuido para orquestar y supervisar en tiempo real sesiones formativas con visores de Realidad Mixta (Meta Quest) en sedes de todo el mundo.

  • Portal web Flask 3.0 con RBAC, CSP Nonces y tematización accesible (Variables HSL).
  • API-Servidor en FastAPI para comunicación de alta frecuencia y baja latencia con visores.
  • Integración de IA con transcripción Fast-Whisper (STT) y síntesis vocal Coqui (TTS).
  • Monitor en vivo (Live Tracker) con generación de códigos PIN para activación en aula.
Flask 3.0 FastAPI Meta Quest MR Fast-Whisper STT Coqui TTS MariaDB / Redis Docker

Proyecto Corporativo Correos y Telégrafos

Conteo Correos: Auditoría de Casilleros por IA

Solución integral para auditar la carga postal pendiente en casilleros de Unidades de Reparto (UR) mediante captura móvil nativa y análisis fotográfico.

  • App Android nativa en Kotlin para captura en hitos críticos (salida a ruta y cierre de turno).
  • Portal web distribuido en Python Flask con histórico y analítica de los últimos 7 días.
  • Seguridad multicapa por anillos de protección (Área → Zona → Sector → Unidad de Reparto).
  • Módulo de visión artificial para estimación volumétrica de correspondencia sin entregar.
Kotlin (Android) Python Flask Visión Artificial MariaDB RBAC Multicapa Arquitectura Distribuida
Logística Postal
Proyecto de Honor Universidad de Alcalá (UAH)

Marchel: Central Telefónica PBX VoIP con Asterisk

Infraestructura PBX IP integral basada en Asterisk v22.2.0, con protocolo PJSIP, síntesis Festival TTS, árbol IVR interactivo y sistema de tarificación CDR.

  • Despliegue sobre Ubuntu Linux en modo bridge con soporte para softphones SIP/PJSIP.
  • Menús interactivos IVR, colas de atención, buzón de voz (Voicemail) y salas de audio.
  • Síntesis de voz dinámica integrada mediante Festival TTS para locuciones automáticas.
  • Panel de control web en Flask y motor de facturación basado en registros MariaDB CDR.
Asterisk 22 VoIP / PJSIP Festival TTS Python Flask MariaDB CDR Linux Ubuntu

Redes & Cloud Universidad de Alcalá (UAH)

Nika App & Microservicio Serverless de Facturación

Plataforma de chat bidireccional en tiempo real inspirada en Sun God Nika (One Piece), combinando WebSockets con tarificación serverless en AWS Lambda.

  • Canales WebSockets de baja latencia con Flask-SocketIO para salas grupales y privados.
  • Microservicio serverless en AWS Lambda para procesamiento automatizado de facturación.
  • Base de datos en la nube desplegada en AWS RDS MySQL con pooling de conexiones.
  • Panel de analíticas de tráfico con estadísticas de consumo en vivo.
Flask-SocketIO WebSockets AWS Lambda AWS RDS MySQL Cloud Serverless Python
